# פתרון ענן — GitHub Actions

הסורק רץ גם בענן, בלי תלות במחשב המקומי או ברשת המקומית.

## מה רץ בענן

| Workflow | לוח (ישראל) | מה עושה |
|---|---|---|
| `open_pre.yml` | 15:45 (ימים ב') | סריקה מוקדמת + מסירה |
| `open.yml` | 16:05 (ימים ב') | סריקת הפתיחה + מסירה |
| `daily.yml` | ידני (`workflow_dispatch`) | סריקה מלאה + דוח + מסירה |
| `favorites.yml` | ידני (`workflow_dispatch`) | מועדפים לקראת הפתיחה + מסירה |
| `watch.yml` | ידני (`workflow_dispatch`) | סריקת מעקב; מסירה רק כשיש שינוי |

שתי סריקות הפתיחה חייבות להישאר workflow-ים נפרדים — בקובץ אחד הריצה השנייה
נדחקה ובפועל רצה רק אחת ביום.

## מסירה

המסירה היא דרך טלגרם (`cloud/deliver.py`). דורש שני סודות ב-Repository Settings → Secrets:

- `TELEGRAM_TOKEN` — טוקן בוט טלגרם (מ-@BotFather)
- `TELEGRAM_CHAT` — מזהה הצ'אט (למשל `5861893315`)

אם הסודות לא מוגדרים, הסקריפט מדפיס את התוצאה ללוג במקום לשלוח.

## מטמון

ההיסטוריה של המניות/תעודות סל נשמרת ב-Actions cache (`cache/`), כך שריצות חוזרות
לא מורידות את ההיסטוריה מחדש. אוניברסום תעודות הסל (`etf_universe.json`) נשמר ברפו.

## הערות

- לוחות הזמן מוגדרים ב-UTC (13:45 / 14:05 = 15:45 / 16:05 ישראל בחורף). בקיץ (IDT, UTC+3) יש להזיז בשעה אחת.
- זיהוי המתעד של GitHub נדחה לעיתים ב-20–50 דקות; אי-הגעה בשעה המדויקת אינה תקלה.
- מגבלת המחשבון החינמי של GitHub Actions: 2,000 דקות/חודש לרפו פרטי.
