# 📈 סורק נאסדק — המלצות עסקאות יומיות

סורק אוטומטי של **מניות ותעודות סל אמריקאיות** (NASDAQ + NYSE + Dow), שמפיק המלצות עסקאות
יומיות (סווינג 1–5 ימי מסחר) מאסטרטגיית מגמה/מומנטום מרובת-אותות. מקור הנתונים: **Nasdaq Public API** (ללא מפתח, ללא עלות).

## מה הוא עושה

1. **רשימה** — שולף את **כל המניות האמריקאיות** (NASDAQ + NYSE + אחרות, ~7,200) ואת **כל תעודות הסל** (~5,400).
   מניות מסוננות לפי: מחיר ≥ $5, שווי שוק ≥ $500M, מחזור דולרי ≥ $20M, ללא מועדונים/אגרות/קרנות/SPAC,
   ומדה-דופליקציה של מחזורים כפולים (GOOGL/GOOG). תעודות סל מסוננות לפי מחיר ומחזור דולרי.
2. **דירוג** — מניות: **2,000 הכי נוזליות** (לפי מחזור דולרי); תעודות סל: כל אלו עם מחזור ≥ $20M.
3. **היסטוריה** — מוריד שנתיים של נתוני יומי (OHLCV) לכל מניה, עם מטמון מקומי.
4. **אינדיקטורים** — SMA20/50/200, RSI(14), MACD(12,26,9), ATR(14), יחס מחזור, מבנה מחיר.
5. **ציונים** — מחשב ציון לונג/שורט (0–15) + מדד איכות רציף לדירוג משנה.
6. **המלצות** — בונה עסקה: כניסה, סטופ (1.5×ATR), יעד (2R), היקף מוצע לתיק של $10,000 בסיכון 1%.
7. **דוח** — מפיק דוח HTML מעוצב + Markdown + JSON, ומדפיס סיכום למסוף.

## התקנה והרצה

דרישות: Python 3.7+ ו-`requests` (במחשב זה כבר מותקן).

```bash
cd C:/Users/user/nasdaq-scanner

# סריקה מלאה (~2,000 מניות + תעודות סל, ~10 דקות בפעם ראשונה)
python3 scanner.py

# סריקה מהירה לבדיקה
python3 scanner.py --universe 100 --top 10

# סריקה עם נתונים טריים (עקף מטמון)
python3 scanner.py --refresh

# בנייה מחדש של אוניברסום תעודות הסל (פעם בשבוע / לפי הצורך)
python3 scanner.py --rebuild

# אבחון — התפלגות ציונים
python3 scanner.py --debug

# מצב מעקב שוטף 24/7 (מדפיס רק שינויים ברשימת המועדפים)
python3 scanner.py --watch --interval 900

# סיכום מועדפים לקראת הפתיחה
python3 scanner.py --brief

# מרווח מטמון מותאם (שניות) — למעקב אינטרה-דיי
python3 scanner.py --watch --interval 900 --ttl 3600
```

## פלט

| קובץ | תיאור |
|------|-------|
| `reports/report_YYYYMMDD_HHMM.html` | דוח ויזואלי מלא (טבלה + מגמת 60 יום + מובילי תעודות סל) |
| `reports/report_YYYYMMDD_HHMM.md` | סיכום Markdown |
| `reports/signals_YYYYMMDD_HHMM.json` | נתונים גולמיים (לניתוח נוסף) |
| `cache/*.json` | מטמון היסטוריה (תוקף 3 שעות) |
| `etf_universe.json` | אוניברסום תעודות הסל (נבנה פעם בשבוע) |
| `watchlist.json` | רשימת המועדפים הנוכחית (לקראת הפתיחה) |

## האסטרטגיה

**לונג** — מחיר מעל SMA50, SMA50 מעל SMA200, RSI בטווח 50–70, MACD חיובי ועולה,
מחזור ≥ 1.2× מהממוצע, מחיר קרוב לשיא 20 יום.

**שורט** — הפך (מחיר מתחת ל-SMA50, SMA50 מתחת ל-SMA200, RSI 30–50, MACD שלילי ויורד).

**ניהול סיכונים** — סטופ 1.5×ATR (מקסימום 10% מחיר), יעד 2R, סיכון 1% מהתיק לעסקה.
מניה נדחית אם סיכון הסטופ עולה על 10%.

## תזמון אוטומטי

מוגדרות שלוש משימות cron (מנוהלות דרך `cronjob_manage`):

| משימה | שעה (ישראל) | תיאור |
|-------|-------------|-------|
| דוח יומי | 23:15 | סריקה מלאה אחרי סגירת נאסדק + דוח מלא בצ'אט |
| מועדפים לקראת הפתיחה | 16:20 | רשימת מועדפים עם סטופ/יעד, 10 דקות לפתיחה |
| מעקב שוטף | כל 15 דקות (24/7) | מעקב על 2,000 מניות + 625 תעודות סל; מוניטור מונע הפעלת LLM כשאין שינוי |

המעקב השוטף משתמש במטמון של 12 שעות (נתוני יומי משתנים פעם ביום); הדוח היומי מרענן
את המטמון עם `--refresh`.

## מועדפים לקראת הפתיחה

`--brief` מסנן את האותות לציון >= 12, מזניק פערים קיצוניים (מניה שצנחה/זינקה יותר מ-5%
נגד כיוון העסקה) ומדרג לפי ציון + איכות. מניות עם פער חיובי מוגדר מעל 8% מקבלות דגש
`⚠️פער` וקנס באיכות. הרשימה נשמרת ב-`watchlist.json`.

**חשוב:** שעות המסחר האמריקאיות הן 09:30–16:00 ET = 16:30–23:00 ישראל (שיא קיצוני של
פרה-מרקט 11:00 ואחרי המסחר עד 03:00). מחוץ לחלון הזה הנתונים לא זזים, ולכן המוניטור
פשוט מדלג על ההפעלה.
